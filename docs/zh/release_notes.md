## v1.0.0

### 更新说明

本次为第一次正式发布。

本版本面向鲲鹏平台的L3缓存访问场景，提供基于大页内存和固定物理偏移布局的内存申请与释放接口，并支持多线程绑核、预热和吞吐测量，为分析内存地址分布对缓存访问的影响提供支持。
